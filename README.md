## ⏱️ The 20-Minute Subscription Audit

Before migrating anything, open your bank/card statement and label each recurring software charge with one word:

1. **Weekly** — You opened it in the last 7 days.
2. **Monthly** — You opened it this month, but not this week.
3. **Never** — You are paying for the *idea* of being the kind of business that uses it.

> **Rule:** Cancel the **Never** column today (no migration needed). Replace the **Monthly** column with a free tier. Keep only the **Weekly** column.

2. **Anything holding proprietary client data you could not reconstruct in 24 hours.** Always run a monthly CSV backup of CRM and subscriber lists.
